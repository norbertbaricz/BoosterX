BoosterX 4.9.5 — C# / .NET 10 Windows Forms / Form1

WINDOWS SOURCE START
Extract the source ZIP. Open the BoosterX folder containing BoosterX.csproj.
dotnet run

PORTABLE START
Extract the full ZIP. Start Portable/win-x64/BoosterX.exe on Intel/AMD Windows,
or Portable/win-arm64/BoosterX.exe on ARM64. The runtime is included.

WINDOW / BACKGROUND
X or Alt+F4 hides the app to the notification area; active work continues.
Left-click the icon or choose Open BoosterX/Open Activity to restore the window.
Right-click -> Quit exits completely. During work it waits for the current action
and skips remaining actions, using the existing Stop behavior. The tray icon
stays available even when pop-up desktop notifications are disabled.

FOOTER
The rounded progress panel fills the footer space beside Stop after current
action, with a fixed percentage column and equal outer insets. Idle means an
empty track and 0%. Operations start fresh and use reported work/native progress;
unknown phases animate at 0% until a real percentage is available. Success, errors
and cancellation all return the footer to idle; results remain in Activity and
History. Hover progress for the latest status. Sidebar: Made by Skypixel Framework.

CLEANUP
Scan cleanup areas automatically checks all 22 fixed catalog areas. There is no
area selector or expandable checkbox list. Active/unavailable caches are skipped.
Review the file preview, then delete after confirmation. File ages, locks,
links, changed files and catalog boundaries are still checked before deletion.
The read-only Windows Update/BITS idle check from 4.9.1 is retained.

REPAIRS
The same 28 individual buttons, headings, descriptions and search are retained.
Page height is measured from actual required content, so an older tall layout
cannot keep a blank scroll area after resize/search. Text measurements are
cached until width, DPI or content changes. Details still stack on narrow pages.
Results appear in Activity/History; servicing is allowed to finish.

34 preferences, installed AppX/Win32/MSI inventory, Startup, Network, Activity,
History, work percentages and the accepted dark controls/icons are retained.
Startup: 1280x720 logical pixels, fitted to the monitor work area.

Applying changes requests elevation. Review selections again after restart;
user settings target the account used for elevation. Publisher uninstallers can
retain shared files/profiles and show their own prompts. File/app removal and
Windows maintenance have no BoosterX undo. No performance gain is promised.

CHECKS
89 pure checks passed. Both portable builds and ZIP integrity/source identity
were checked. The actual source ZIP was extracted/rebuilt and checked again.
36 native fixtures and 143 layout cases are prepared; they require Windows and
were not executed on this Linux build host. See docs/WINDOWS-TESTING.md.
